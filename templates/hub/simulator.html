Calling the webhooks from the command line

The simulated providers sign the raw body with HMAC-SHA256 using the secrets from .env (HUB_SIM_WHATSAPP_APP_SECRET, HUB_SIM_SIP_SECRET). For example:

BODY='{"call_id":"c-42","event":"ringing","from":"+60111","to":"{% if let Some(v) = voice.first() %}{{ v.address }}{% else %}+6032000xxxx{% endif %}"}'
SIG="sha256=$(printf %s "$BODY" | openssl dgst -sha256 -hmac "$HUB_SIM_SIP_SECRET" | sed 's/^.* //')"
curl -s -X POST {{ base_url }}/v1/hub/channels/sip/events -H "X-Sim-Signature: $SIG" -H 'content-type: application/json' -d "$BODY"
